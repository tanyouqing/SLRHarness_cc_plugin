## 查阅提示

- ICLR：Author Guidelines 包含匿名、正文及附录长度、声明和 camera-ready 要求。
- ICML：Author Instructions 同时包含投稿与 camera-ready 要求；官方 example_paper.tex 说明具体排版。
- AAAI：Submission Instructions 与 Author Kit 配套使用，含版式、匿名、内容长度和可复现性清单；本次下载入口重定向到 2026/10 版本。
- ACL / EMNLP：同时保留当届征稿页、ARR 投稿要求和 ACLPUB 排版指南；共同使用固定提交版本的 ACL 样式。
- NeurIPS（旧称 NIPS）：Main Track Handbook 与 Call for Papers 配套；原始包中的 neurips_2026.tex 和 checklist.tex 也包含格式说明。

年份表示已经核实并下载的官方版本。ACL 共享库没有独立年号，不能仅根据会议年份重命名样式或推断规则。每次正式投稿前应重新核实目标年份与 track；本地保留版权和原始说明。
