## 实现范围

- 保留当前 schema 2、Manager 逐篇验收、Checker 章节检查、会议格式检查、分阶段写作和 Reviewer 输入隔离。
- `.slr/survey-kb.json` 保存每次调研的不可变开关、runId 和预算。缓存、导入来源、轨迹、队列独立放在 `.slr/kb/`，不进入论文验收指纹。
- 精确识别 `mcp__survey-kb__`，核对实际 Agent 绑定、活动任务、角色、阶段和参数；Worker 论文权限、四类角色自身策略权限与脚本专有提交权限分离。
- 同步 PostToolUse 保存完整响应并替换展示，Unicode 字符预算包含 JSON 转义和定位信息；按任务/角色/阶段/参数缓存，错误不缓存为空命中。
- Manager 登记时验证 Worker 缓存中的论文身份与修订，沿用唯一归属；导入不覆盖本地笔记。验收后立刻冻结允许元信息及完整 note，成功收尾时扫描补漏，重新验收后新内容产生新项。
- Reviewer 可以读取自身历史 experiences 与对照依据，继续隔离研究日志和 KB；仅最终成功报告进入直接提交。出站省略 null/空可选字段，原审稿记录不改写。
- 会话、子 Agent 和工具生命周期 Hook 采集原生完整 JSONL 行；主会话从本次请求边界开始，子轨迹使用自身路径。保留偏移、行号映射、哈希、父子绑定和可识别的接续关系。
- 完成门槛结合当前最终审稿、证据/稿件、阶段和活动任务，并由主会话 Stop 发起收尾；成功 Stop 自动启动独立单次同步，不要求退出会话，不在主状态锁内联网。
- 本地内容哈希队列、进程锁和 120 秒租约，串行 20 秒请求、最多 3 次暂时错误尝试、2/5 秒退避、15 秒轮询、30 分钟跟踪窗口。服务端失败保留原 job。
- 提供项目 MCP、CLI 状态/整批单次同步/恢复与外层启动脚本、云端只读验收、隔离模拟 MCP 的原生能力探针和中文部署手册。

## 2026-10-27：成功后单次同步（0.9.1）

按用户确认，取消 Pipeline 常驻上传服务，移除 watch 命令及 systemd/服务环境模板。已验收论文仍在执行期冻结本地内容，但与最终审稿经验、轨迹一起等待整个调研成功。processOne 的联网入口也校验当前成功状态与 Stop 指纹，避免手动 once 绕过成功门槛。
